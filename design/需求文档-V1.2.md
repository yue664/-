## 二、第五章主线 + 5 分支结局（F-V12-01/02）

### 2.1 章节定位

- **章节**：第五章「魔王城 · 忠诚与背叛」
- **BOSS**：Meido（最终 BOSS，魅魔转化形态）
- **时长**：主线 5-8h
- **调性**：情色正剧终章——忠诚与背叛的抉择，Meido 转化全貌揭露，主角命运落定

### 2.2 章节流程（交互说明）

```
第四章末尾（Rushena 契约线收口）
  └─ 进入魔王城（2D 像素场景）
      ├─ 5-1 魔王城前庭：Meido 迎接，状态异常（伏笔：转化已开始）
      ├─ 5-2 魔王城回廊：5 女主集结，契约回顾（回忆杀 ×3 短事件）
      ├─ 5-3 王座之间：Meido 魅魔转化觉醒（T0 事件，CG-01/02）
      ├─ 5-4 最终 BOSS 战（Meido 转化形态，H-MID 框架复用）
      │    ├─ 分支 A：战败 → Meido 捕获（堕落值 +15，转 5-5 堕落分支）
      │    └─ 分支 B：胜利 → 净化/契约抉择（转 5-5 净化分支）
      └─ 5-5 终局抉择（5 分支结局判定 → 结局画廊解锁）
```

### 2.3 5 分支结局条件表（核心数值）

| 分支 ID | 结局名 | 触发条件 | 画廊 CG | 备注 |
|---|---|---|---|---|
| E5-1 | 魔王加冕 | 堕落值 ≥ 100（is_fallen） | CG-03（CielArt） | 主角彻底怪物化，加冕魔王 |
| E5-2 | 堕落契约·Meido | Meido 契约度 = 100 且 堕落值 ≥ 80 | 复用 H-MID-005 | Meido 线主结局 |
| E5-3 | 全员堕落 | 5 女主契约度 ≥ 70 且 堕落值 ≥ 70 | CG-08（Indie） | 全员堕落群像 |
| E5-4 | 勇者归来 | 堕落值 < 50（净化 Meido 成功） | 复用 T0 结局 CG | 反 H 线，救世主结局 |
| E5-5 | 混沌真结局 | 5 女主契约度 = 100 且 堕落值 = 100 | CG-04（CielArt） | 隐藏真结局，全收集解锁 |

**判定优先级**：E5-5 > E5-1 > E5-2 > E5-3 > E5-4（与数值设计 check_ending_condition 一致）

**存档字段（追加到 SaveManager，S8-03）**：
```json
{
  "meta": {"version": "1.2.0"},
  "chapter5": {
    "stage": "5-1",                    // 当前章节阶段
    "meido_transformed": false,        // Meido 是否已转化（BOSS 战前）
    "boss_defeated": false,            // 是否战胜最终 BOSS
    "ending_branch": "",               // 5 分支结局 ID（E5-1~E5-5）
    "choice_5_5": ""                   // 终局抉择选项（净化/契约/臣服/堕落/混沌）
  }
}
```
- **升级规则**：V1.1 老档无 `chapter5` 字段 → SaveManager 初始化默认值（stage="5-1", 全 false），不阻塞、不崩溃（null-safe 加固点）
- **校验**：陈验 TC-SAVE-001~010（10 条存档兼容用例）

## 四、多语言标点 lint 前置（F-V12-04）

### 4.1 规则表（赵画排版规范 → lint 规则库）

| 规则 ID | 语言 | 规则 | 示例（违规） |
|---|---|---|---|
| LINT-001 | 繁中 | 全角标点「，。」与相邻字符不得挤压 | 「愛してる，」→ 半角逗号违规 |
| LINT-002 | 日 | 句读号「、。」后必须换行或空格规则 | 行尾「。」后接英文无空格 |
| LINT-003 | 韩 | 引号「”」前不得直接跟半角字符 | 「”hello」→ 违规 |
| LINT-004 | 全 | 词条内禁止混用半角/全角标点（同语境） | 「Good。job」→ 混用违规 |
| LINT-005 | 全 | 数字/英文与中文间须加空格（CJK-Latin spacing） | 「第5章」→ 应为「第 5 章」 |
| LINT-006 | 全 | 行首禁标点（避头尾） | 换行后「。这是」→ 违规 |

### 4.2 流程（交互说明）

```
李游交付词条（UTF-8 JSON）
  └─ CI 触发 lint 脚本（王码实现，规则库来自赵画规范）
      ├─ 通过 → 进包
      └─ 不通过 → 返回李游修订（标注违规行号+规则 ID）
```
- 老词条 2,386 条 D4 前全量回扫（陈验）
- 陈验 3 条 lint 验收用例（TC-LINT-001~003）
