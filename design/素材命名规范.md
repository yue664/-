## 一、总原则

| 项 | 规范 |
|---|---|
| 目录 | 小写短横线（`assets/cg_2d/`） |
| 文件名 | 小写下划线（`artesia_cg_001.png`） |
| 版本后缀 | `_v02` / `_v03` 递增 |
| 双轨后缀 | `_pc`（Steam）/ `_android`（Android 专用） |
| LOD 后缀 | `_lod0`（高）/ `_lod1`（中）/ `_lod2`（低 5000 面） |
| 表情后缀 | `_neutral` / `_mouth_open` / `_sigh_blush` / `_tear_cry` |
| 大小写 | 严格小写（跨平台文件系统兼容） |
| 空格/中文 | 禁止 |
| 版本号 | 文件名或目录名内加 `_v02`，不用文件名外 |

## 二、角色资源命名

### 2D 立绘（双平台共用）

```
assets/portraits/{char_id}.png
```

- `{char_id}`：`artesia` / `marina` / `mei` / `rushena` / `meido`
- 尺寸：1080×1920
- 格式：PNG → WebP quality=85

### 2D 立绘表情差分（Android 专用，双平台可选）

```
assets/portraits_expressions/{char_id}_{expression}.png
```

- `{expression}`：`neutral` / `mouth_open` / `sigh_blush` / `tear_cry`
- 5 女主 × 4 表情 = 20 张
- 回退：无匹配时 fallback 到 `assets/portraits/{char_id}.png`

### 3D 模型（双轨：Steam PC + Android LOD）

```
assets/models/heroines/{char_id}/{char_id}_lod0.gltf          # Steam PC 1-2 万面
assets/models/heroines/{char_id}/{char_id}_lod2.gltf          # Android 5000 面
assets/models/heroines/{char_id}/textures/                    # 贴图共用
assets/models/heroines/{char_id}/blend_shapes.json            # Blend Shape 元数据
```

- LOD 切换：`PlatformManager.can_use_3d_cinematic()` 返回 true → lod0；false → lod2（且手机端根本不加载 3D）
- Blend Shape：8 个基础表情（neutral/smile/angry/sad/surprised/kiss/blush/pleasure）

## 三、H 事件资源命名（双平台混合结构）

```
assets/events/{char_id}/{event_id}/
├── scene_3d.tscn              # Steam PC 场景（Android 不加载）
├── cg_2d_sequence.json        # Android 分镜序列（Steam 不加载）
├── dialog.json                # 共用剧本
├── audio/                     # 共用语音
│   ├── bgm.ogg
│   └── se/
├── meta.json                  # 级别/契约度增量/结局分支
└── README.txt                 # 事件说明（可选）
```

**event_id 命名**：`H-{CHAR}-{NUM}`
- 例：`H-ART-001`（Artesia 初夜）、`H-MA-005`（Marina 结局）

**meta.json 结构**：
```json
{
  "id": "H-ART-001",
  "tier": "T0",
  "contract_delta": 25,
  "corruption_delta": 10,
  "ending_branch": "art_fallen_contract",
  "requires": {"contract_min": 0, "affection_min": 50},
  "skip_allowed": false,
  "linked_risk": "R-017"
}
```

## 四、2D CG 命名（Android 专用）

```
assets/cg_2d/{char_id}/H-{CHAR}-{NUM}_{seq}.png
```

**示例**：
```
assets/cg_2d/artesia/H-ART-001_01.png    # 初夜·契约确认 第1张
assets/cg_2d/artesia/H-ART-001_02.png
assets/cg_2d/artesia/H-ART-001_03.png
assets/cg_2d/artesia/H-ART-001_04.png
assets/cg_2d/marina/H-MA-001_01.png
assets/cg_2d/marina/H-MA-001_02.png
...
```

**cg_2d_sequence.json**（Android 播放分镜顺序）：
```json
{
  "event_id": "H-ART-001",
  "duration_ms": 5000,
  "sequence": [
    {"file": "H-ART-001_01.png", "duration": 3000, "camera": "static"},
    {"file": "H-ART-001_02.png", "duration": 2000, "camera": "zoom_in"},
    {"file": "H-ART-001_03.png", "duration": 2500, "camera": "shake"},
    {"file": "H-ART-001_04.png", "duration": 4000, "camera": "fade_out"}
  ],
  "bgm": "assets/events/artesia/H-ART-001/audio/bgm.ogg",
  "dialog_id": "H-ART-001"
}
```

## 五、战斗/场景资源命名

```
assets/tiles/{scene_id}/tile_{x}_{y}.png          # 32x32 像素 tile
assets/tiles/{scene_id}/tileset.json              # 场景配置
assets/tiles/{scene_id}/background.png            # 战斗背景大图
```

**scene_id**：`slime_cave` / `demon_castle` / `siren_reef` / ...

## 六、UI 资源命名（双轨独立）

```
assets/ui/mouse/            # 鼠标 UI（Steam PC）
assets/ui/touch/            # 触控 UI（Android）
```

**触控 UI 尺寸**：
- 按钮最小 96×96 px（Android 触控阈值）
- 图标 64×64 px
- 字号 ≥24 px

---

## 七、音频命名（双平台共用）

```
assets/audio/bgm/{theme_id}.ogg                    # BGM
assets/audio/se/{event_id}_{action}.ogg            # SE
```

**例**：
```
assets/audio/bgm/theme_menu.ogg
assets/audio/bgm/theme_battle_slime.ogg
assets/audio/se/H-ART-001_breath.ogg
assets/audio/se/battle_hit_slime.ogg
```

## 八、双轨清单（一图看懂）

| 素材类型 | Steam PC | Android | 目录 |
|---|---|---|---|
| 2D 立绘 | ✅ | ✅ | `portraits/` |
| 2D 表情差分 | 部分 | ✅ 必做 | `portraits_expressions/` |
| 3D 模型 lod0 | ✅ | ❌ | `models/heroines/{id}/` |
| 3D 模型 lod2 | 备用 | ✅ 但不用（关闭 3D） | `models/heroines/{id}/` |
| 2D CG | ❌ | ✅ 必做 | `cg_2d/` |
| 战斗 tile | ✅ | ✅ | `tiles/` |
| UI 鼠标 | ✅ | ❌ | `ui/mouse/` |
| UI 触控 | ❌ | ✅ | `ui/touch/` |
| 音频 | ✅ | ✅ | `audio/` |
| 事件剧本/语音 | ✅ | ✅ | `events/{id}/dialog.json + audio/` |

## 九、Git LFS 使用

**必须走 LFS 的大文件**：
- `*.png` > 100KB
- `*.gltf`
- `*.glb`
- `*.ogg`
- `*.mp4`

**`.gitattributes` 已配置**（王码 D2 交付）：
```
*.png filter=lfs diff=lfs merge=lfs -text
*.gltf filter=lfs diff=lfs merge=lfs -text
*.glb filter=lfs diff=lfs merge=lfs -text
*.ogg filter=lfs diff=lfs merge=lfs -text
```

## 十、双平台打包差异

| 项 | Steam PC | Android |
|---|---|---|
| 加载 3D 模型 | ✅ lod0 | ❌（`PlatformManager.can_use_3d_cinematic() == false`） |
| 加载 2D CG | ❌ | ✅ |
| 加载 UI 鼠标 | ✅ | ❌ |
| 加载 UI 触控 | ❌ | ✅ |
| 加载 lod2 模型 | ❌ | ✅（备用，实际不加载） |
| 加载表情差分 | 部分（Blend Shape 替代） | ✅ |
