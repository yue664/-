## 一、核心数值一览

| 数值 | 范围 | 类型 | 说明 |
|---|---|---|---|
| **契约度** `contract` | 0-100 | int | 每女主独立，H 事件主驱动 |
| **好感度** `affection` | 0-100 | int | 每女主独立，对话选择主驱动 |
| **堕落值** `corruption` | 0-100 | int | 主角全局，H 事件/战败/道具叠加 |
| **主角等级** `level` | 1-50 | int | 战斗成长 |
| **HP** | 1-999 | int | clamp 上限 |
| **MP** | 0-999 | int | clamp 上限 |
| **金币** | 0-999999 | int | clamp 上限 |

**溢出保护**：所有 add_* 方法强制 clamp（王码 GameManager 已实装）

## 五、契约度/好感度/堕落值联动规则

```
契约度 = f(H 事件)   # 主要来源
好感度 = f(对话 + 战斗救援)   # 主要来源
堕落值 = f(H 事件 + 战败 + 道具)   # 全局来源
```

### 触发判定逻辑（伪代码）

```gdscript
func check_event_trigger(event_id: String) -> bool:
    var e = EVENT_REGISTRY.get(event_id)
    return (
        GameManager.contract[e.char_id] >= e.contract_min and
        GameManager.affection[e.char_id] >= e.affection_min and
        GameManager.corruption >= e.corruption_min and
        not EVENT_STATE.has(event_id)  # 幂等：已触发不重复
    )
```
