## 二、视觉风格（v0.2 修订）

### 2.1 场景层：2D 像素

- 俯视 45°（Tactical RPG 视角）
- 分辨率：场景 tile 16×16 或 32×32
- 地图：手绘半像素风，暗黑哥特调性
- 光照：像素光效（torchlight/vignette）
- 目标：MVP 5 张地图（主城/下水道/魔界/女仆馆/魔王城）

### 2.2 立绘层：3D 模型

- **战斗/H 事件中用 3D 模型演出**
- 女主各 1 个 3D 全身模型（Blender 建模，卡通渲染 Cel-Shading）
- 表情差分：头部替换（每角色 3-5 张脸）
- 动作：基础 idle + 4-6 战斗动作 + 3-5 H 事件动作
- 渲染：Godot 4.3 内置 SpatialMaterial + 自定义卡通 Shader
- 参考：Fate/Grand Order 3D 卡面 / 异度神剑 2 卡通渲染

### 2.3 UI 层

- 暗黑哥特金边风格
- 字体：得意黑（标题）+ ZCOOL KuaiLe（正文）
- 像素字体：Press Start 2P（用于像素 UI 元素）

## 三、玩法系统

### 3.1 战斗（回合制）

- 回合顺序：主角 → 敌方 → 主角
- 属性克制：神圣 → 魔族 → 兽族 → 人族 → 神圣（循环）
- 主角属性：HP 100 / MP 50 / ATK 20 / DEF 15 / AGI 25
- 技能树：4 系（神圣 / 黑暗 / 物理 / 辅助）× 3 层 = 12 技能
- 战败：**可捕获**——触发 H 事件或惩罚分支（不做永久死亡）

### 3.2 数值体系（简化版）

| 数值 | 上限 | 说明 |
|---|---|---|
| 等级 | 50 | 主角上限 |
| 契约度 | 100 | 与女主感情线，影响结局 |
| 堕落值 | 100 | 主角堕落度，触发怪物化 |
| 好感度 | 100 | 每个女主独立 |
| 支配度 | 100 | 调教系统解锁条件 |

### 3.3 H 系统

- 5 位女主各自独立 H 事件线
- 调教链：3 基础动作 + 5 道具（MVP）
- 特殊要素：触手 / NTR / 怪物化 / 强制 / 羞耻（MVP 起全开）
- 契约度阈值：30/60/90 触发三级解锁
- 结局 CG：每位女主 3-5 张，含 H 结局

### 3.4 结局结构

- 主线 4 结局：勇者归来 / 沉沦黑暗 / 全员堕落 / 魔王加冕
- 女主结局：每位 3-4 结局 = 17 个结局总数
- 隐藏结局：契约度全满 + 堕落值 100 = 真结局

## 四、世界观框架（待细化）

### 4.1 基本设定

- **时代**：西方中世纪幻想
- **地理**：阿尔卡迪亚大陆，分人族王国 / 魔族领地 / 兽人部落 / 中立地带
- **神系**：光明神（秩序/正义）vs 混沌神（欲望/自由）
- **主角起源**：被选中的勇者，拯救阿尔卡迪亚的使命
- **核心冲突**：勇者 vs 魅魔军团，但魅魔有各自的动机与欲望

### 4.2 5 位女主的定位（初版）

| 角色 | 种族/身份 | 主线定位 |
|---|---|---|
| Artesia | 前圣女 → 堕天使 | 主角最初救赎的对象，情感主线 |
| Marina | 深海人鱼 / 魅魔混血 | 海洋篇，欲望/欺骗主题 |
| Mei | 东方女武神 | 武道篇，肉体改造/支配主题 |
| Rushena | 吸血鬼伯爵 | 魔界篇，寿命/契约主题 |
| Meido | 魔王城女仆 | 支线/日常，忠诚/背叛主题 |

### 4.3 关键剧情节点（待李游细化）

- 序章：勇者召唤 → 遇袭 → 契约度 0
- 第一幕：Artesia 堕落 → 主角动摇
- 第二幕：Marina 引导入欲望深渊
- 第三幕：Mei 肉体改造，堕落值飙升
- 第四幕：Rushena 契约诱惑
- 终幕：Meido 忠诚与背叛，真结局判定

## 五、素材与技术约束

### 5.1 素材来源

- MVP 阶段：复用 RMMZ 提取素材（tile/立绘/音频）
- 立绘：MVP 复用 2D 立绘；Sprint 1 起补 3D 模型（Blender + Mixamo 动作）
- 正式版前 3 个月启动替换（Steam 上架合规）

### 5.2 技术栈

- 引擎：Godot 4.3 + GDScript
- 3D 渲染：Godot 内置卡通 Shader（Sprint 1 引入）
- 存档：JSON + 版本迁移框架
- 性能目标：立绘/3D 切换 <300ms
