# 安卓降级剧情方案

> 维护人：李游（策划师）
> 版本：v0.1（Sprint 0 D3）
> 关联：R-014（手机端 3D 性能）、R-015（双平台维护）
> 技术接口：`PlatformManager.can_use_3d_cinematic()` 返回 false 时启用本方案

---

## 一、降级总原则

**手机端 = 2D CG 演出 + 2D 立绘表情差分 + 语音/字幕**，不做实时 3D。

| 特性 | Steam PC | Android |
|---|---|---|
| 3D 立绘实时演出 | ✅ 全开 | ❌ 关闭 |
| H 事件高潮 CG | 3D 模型 Blend Shape 表情 + 相机运镜 | 2D CG（静态 + 微动） |
| 表情差分 | 3D Blend Shape | 2D 立绘表情差分（张嘴/闭嘴/泪目/娇喘） |
| 对话立绘 | 3D 半身 + 微动 | 2D 立绘（含表情差分） |
| 战斗演出 | 2D 场景 + 3D 女主 BOSS 出场 | 2D 场景 + 2D CG BOSS 出场 |
| 结局演出 | 3D 混合 | 2D CG 分镜 |

**核心逻辑**：`PlatformManager.can_use_3d_cinematic() == true` 走 3D 管线；`false` 走 2D CG 替代管线。

## 三、2D CG 素材需求（新增给赵画）

### 数量统计

- **T0 事件**：5 女主 × 5 张 CG = **25 张**（必须做）
- **T1 事件**：5 女主 × 12 张 CG = **60 张**（V4.3 内做，V5+ 补完）
- **T2 事件**：5 女主 × 4 组表情差分（4 张/组）= **20 组**（可复用现有立绘，不新做 CG）

**总 2D CG 新增需求**：25 + 60 = **85 张 CG**（首发版本）

### 预算追加

- 单张 CG 外包价：**500 元/张**（赵画口径）
- 首发 T0 + T1：85 张 × 500 = **42,500 元**（不含在 V4.3 预算内）
- **建议**：T0 首发做（25 张 = 12,500 元），T1 分两批做
  - 第一批（Sprint 4 前）：Marina/Mei 各 3 张 × 2 人 = 6 张 × 500 = 3,000 元
  - 第二批（V5+）：剩余 54 张

### 与 V4.3 预算的关系

- V4.3 预算 4000 元：**只做 3D LOD 5000 面 + 触控 UI**（不含 2D CG）
- 2D CG 独立预算：**追加 15,500 元**（T0 全 25 张 + T1 首批 6 张）
- 张策需重新申请预算

## 四、2D 立绘表情差分规范（Android 专用）

每位女主需要 **4 组基础表情差分**：

| 表情 | 用途 |
|---|---|
| Neutral | 对话默认 |
| MouthOpen | 语音同步（张嘴） |
| Sigh/Blush | 娇喘/脸红 |
| Tear/Cry | 哭泣/堕落情绪 |

**产出**：5 女主 × 4 组 = 20 组差分（可复用现有立绘资源，只做局部改）

**赵画工时**：约 3-5 天（复用 2D 立绘基础）

## 五、Android 剧情脚本兼容

### 事件系统判定逻辑

```gdscript
# EventManager.gd（王码实现）
func trigger_h_event(event_id: String) -> void:
    var use_3d = PlatformManager.can_use_3d_cinematic()
    var event_data = H_EVENT_REGISTRY.get(event_id, {})
    
    if use_3d:
        # Steam PC：走 3D 管线
        var scene_path = event_data.get("scene_3d", "")
        get_tree().change_scene_to_file(scene_path)
    else:
        # Android：走 2D CG 管线
        var cg_list = event_data.get("cg_2d_sequence", [])
        _play_cg_sequence(cg_list)
```

### 事件资源结构

```
assets/events/{char_id}/{event_id}/
├── scene_3d.tscn              # Steam PC 场景（含 3D 模型 + 相机）
├── cg_2d_sequence.json        # Android 分镜序列
├── dialog.json                # 共用剧本
├── audio/                     # 共用语音
└── meta.json                  # 级别/契约度增量/结局分支
```

**关键**：`dialog.json` + `audio/` **双平台共用**，只有视觉表现层分离。

## 六、NTR/触手/怪物化特殊处理

### NTR 剧情（P0）

- **Steam PC**：3D 演出（3 人场景 + Blend Shape）
- **Android**：2D CG 分镜（3 张：场景铺垫 / 关键画面 / 主角视角）
- **注意**：Android 侧 NTR 分镜必须保留"主角视角"一张，避免剧透

### 触手演出（P0）

- **Steam PC**：3D 触手（Mixamo 骨骼 + 自定义 mesh）
- **Android**：2D CG（触手为静态分镜，不做骨骼动画）

### 怪物化（P1）

- **Steam PC**：3D 模型变形（Blend Shape）
- **Android**：2D CG 分镜 + 变形前/后对照图

## 七、双平台共享内容（避免重复劳动）

| 内容 | Steam | Android | 是否共享 |
|---|---|---|---|
| 剧情文本（dialog.json） | ✅ | ✅ | **共享** |
| 语音（audio/） | ✅ | ✅ | **共享** |
| 数值变更（corruption/contract） | ✅ | ✅ | **共享** |
| 结局分支逻辑 | ✅ | ✅ | **共享** |
| 3D 演出场景 | ✅ | ❌ | 仅 Steam |
| 2D CG 分镜 | ❌ | ✅ | 仅 Android |
| 3D 立绘模型 | ✅ | ❌ | 仅 Steam |
| 2D 立绘表情差分 | 部分 | ✅ | 主要 Android |
| 战斗场景 tile | ✅ | ✅ | **共享** |
| UI 底图 | 鼠标版 | 触控版 | **不共享**（独立） |

**估算**：Android 侧真正新增的素材 = 85 张 2D CG + 20 组表情差分 + 触控 UI 重做。其他 90% 内容双平台共用。
