## 二、结局定格分镜描述（给画师）

```
事件 ID: H-MA-005
场景序号: 05
场景名称: 深渊契约 · 结局定格
场景描述: 
  主角与 Marina 在深海最深处相拥，主角已被深海契约彻底转化，
  胸口浮现蓝光契约金文，Marina 鱼尾环绕主角，两人的呼吸交融。
  远处深渊水柱向上，海面无光，只有两人的身体散发微光。

关键要素:
  - 主角：凯尔，男性青年，23 岁，深色卷发，蓝眼睛，
    黑色披风被海水浸透半透明，胸口浮现蓝光契约金文（水蓝色符文）
  - Marina：人鱼，蓝色短发，鱼尾（银色鳞片+水蓝色渐变），
    眼角有泪痣，闭眼微笑依偎主角胸口
  - 场景：深海最深处（无光），珊瑚洞外的开阔水域
    远处有深渊水柱向上延伸到模糊海面
  - 光效：主角胸口蓝光契约金文 + Marina 鱼尾银色反光
    为主光源，环境近乎全黑（暗黑哥特基调）
  - 附加元素：发光水母在两人周围漂浮（呼应 H-MA-001 结尾隐喻）

构图: 
  中景偏特写，主角侧脸+Marina 鱼尾环抱，两人脸颊相贴
  画面右侧深渊水柱向上升腾，左侧深海黑暗

氛围: 
  永恒、沉溺、契约既成的宿命感
  不追求"甜美"，追求"深海将吞没一切"的仪式感

镜头: 
  平视视角，两人均在画框内，构图偏右上重
  参考日式厚涂 + 韩式薄涂混合风格

参考: 
  H-MA-001_04.png（契约成立瞬间）的"发光水母散开"意象延续
  但场景从珊瑚洞切到开阔深海，情感从"契约成立"过渡到"永恒沉溺"

技术规格:
  分辨率: 1920×1080（横版）
  格式: PNG 32 位
  色彩: sRGB，深色基调（R<100, G<100, B<150）
  光效: 主角胸口蓝光金文为唯一冷光源
```

## 四、Android/Steam 视觉一致性说明

**Android 侧**：
- 2D CG 定格 + 字幕 + BGM（无 3D）
- CG 加载超时 800ms fallback 到渐变 + 字幕

**Steam PC 侧**：
- 3D 演出（主角+Marina 模型）+ Blend Shape 情绪切换
- 结局定格时镜头拉远，3D 场景过渡到全屏 CG（作为收尾）
- 字幕/演出/时长与 Android 对齐（张策 R-017 一致性）

**共用资源**：
- dialog.json（同一份对白）
- voice/*.mp3（同一份 TTS 语音）
- bgm/theme_ocean_ending.ogg（同一份 BGM）

**差异**：仅 CG 是否加载 + 3D 是否演出。

## 五、给赵画的画师向提示

**给 Indie-H-Comics 分镜描述补充**：
- 风格：韩式薄涂（比 CielArt 日系厚涂更细腻，适合深海氛围）
- 光效控制：单光源（主角胸口蓝光），不做多光源
- 主体位置：画面中心偏左，右侧留白给深渊水柱
- 情绪：不要"甜美"，要"宿命感"
- 参考：CielArt 已出的 H-MA-001_01.png 风格基准（如果 CielArt 先交付），但结局定格可走韩式薄涂差异化

**首张交付验证**：
- 赵画验 CG 与 H-MA-001_04.png（契约成立瞬间）的情绪衔接
- 若风格偏差大，退回画师重做（免费 1 次修改）
