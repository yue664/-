## 一、素材规格

| 项 | 规格 |
|---|---|
| 尺寸 | 1024×1536（竖屏 2:3） |
| 格式 | PNG 24 位（透明背景） |
| 单张大小 | < 2MB（正式） / < 500KB（占位） |
| 命名 | `{heroine_id}_{expression}.png` |
| 提交路径 | `assets/portraits/` |
| WebP 压缩 | Sprint 3 前压缩至 < 800KB/张 |

## 二、画风规范

- **风格**：日系厚涂（承接 Sprint 0 CG 询价单 v0.2）
- **调色**：暗色调为主（18+ 情色正剧基调）
- **人物比例**：9-10 头身
- **表情差分**：5 种（normal/smile/shy/angry/cry 或特殊状态）
