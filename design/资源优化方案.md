## 二、WebP 压缩策略

### 2.1 参数选择

| 素材类型 | 质量 | 目标大小 | 备注 |
|---|---|---|---|
| 战斗 tile（32×32） | quality=80 | <2KB | pngquant 预压 |
| 立绘（1080×1920） | quality=85 | <800KB | 保留透明 |
| 表情差分 | quality=85 | <800KB | 与立绘一致 |
| 2D CG（1920×1080） | quality=88 | <1.2MB | 高质量优先 |
| UI 底图 | quality=85 | <200KB | 保留细节 |
| UI 图标 | quality=90 | <30KB | 小图高质量 |
| BGM | ogg 128kbps | <3MB/首 | |
| SE | ogg 96kbps | <200KB/个 | |

### 2.2 转换命令（Linux/CI）

```bash
# PNG → WebP
cwebp -q 85 input.png -o output.webp

# PNG 预压（无损，保留透明）
pngquant --quality=70-85 --speed=3 --strip --force input.png

# ogg 转码（BGM）
ffmpeg -i input.wav -codec:a libvorbis -b:a 128k output.ogg

# 批量转换脚本
for f in assets/portraits/*.png; do
  pngquant --quality=70-85 --speed=3 --strip --force "$f"
  cwebp -q 85 "$f" -o "${f%.png}.webp"
done
```

### 2.3 CI 集成（王码 D5 接入）

## 三、图集合并（Texture Atlas）

### 3.1 合并策略

**小图合并大图**（减少 draw call）：
- 战斗 tile → `tiles/atlas_combat_2048.webp`
- UI 图标 → `ui/atlas_icons_512.webp`
- 表情差分 → `portraits/atlas_expressions_4x4.webp`（5 女主 × 4 表情）

**不合并**（保留独立加载）：
- 立绘（1080×1920 太大）
- 2D CG（大尺寸独立）
- 3D 模型贴图（PBR 各各的）

### 3.2 图集生成工具

**推荐**：Godot 内置 Atlas Texture 编辑
**备选**：[TexturePacker](https://www.codeandweb.com/texturepacker)（付费）/ [free-tex-packer](https://github.com/arnaudg/free-tex-packer)（开源）

### 3.3 加载优化

```gdscript
# 立绘缓存 LRU（王码实现）
class_name PortraitCache
var cache: Dictionary = {}
var max_size: int = 20  # 20 张
var lru_order: Array = []

func get_portrait(char_id: String, expr: String) -> Texture2D:
    var key = char_id + "_" + expr
    if cache.has(key):
        _touch_lru(key)
        return cache[key]
    var path = "res://assets/portraits_expressions/%s_%s.webp" % [char_id, expr]
    var tex = load(path)
    _put_lru(key, tex)
```

## 七、缓存 LRU 策略（王码实现）

### 7.1 立绘缓存

```gdscript
# PortraitCache.gd
var max_portraits: int = 20
var cache: Dictionary = {}
var order: Array = []

func get_portrait(char_id: String, expr: String) -> Texture2D:
    var key = "%s_%s" % [char_id, expr]
    if cache.has(key):
        order.erase(key)
        order.append(key)
        return cache[key]
    var tex = load("res://assets/portraits_expressions/%s.webp" % key)
    cache[key] = tex
    order.append(key)
    if order.size() > max_portraits:
        var evict_key = order.pop_front()
        cache.erase(evict_key)
    return tex
```

### 7.2 CG 缓存

CG 单张 1-2MB，加载即显示，用完不缓存。

### 7.3 BGM 缓存

```gdscript
# AudioManager.gd
var bgm_cache: Dictionary = {}
var bgm_cache_max: int = 4

func load_bgm_cached(path: String) -> AudioStream:
    if bgm_cache.has(path):
        return bgm_cache[path]
    var stream = load(path)
    bgm_cache[path] = stream
    if bgm_cache.size() > bgm_cache_max:
        var evict_key = bgm_cache.keys().pop_front()
        bgm_cache.erase(evict_key)
    return stream
```
