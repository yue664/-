# Edge TTS vs Azure 付费版评估 v0.1（S5-05a）

> 负责人：王码
> Sprint 5 D2（2024-10-04）
> 关联：R-024 TTS 商用风险应对

## 背景

- 首发 600 句语音用 Edge TTS（免费）
- R-024：Edge TTS 微软 ToS 未明确禁商用，V1 首发风险中
- 需要评估商业化切 Azure 付费版的可行性

## 方案对比

| 项 | Edge TTS（当前） | Azure 付费版 |
|---|---|---|
| 单价 | 0 元 | 4 元/万字符 |
| 600 句 ≈ 6000 字符 | 0 元 | **60 元** |
| 商用权限 | ❌ 未明确（灰色） | ✅ 明确商用授权 |
| 音色数 | 有限（Yunxi 等免费音色） | 完整音色库 |
| 稳定性 | 免费 API 限流 | 付费 SLA 99.9% |
| 集成成本 | 已完成 | 复用 voice_generator.py，加 provider 参数 |

## 决策建议

### 阶段策略

1. **Sprint 5（V1 首发）**：继续使用 Edge TTS（0 元）
   - 单机发行，无商业分发，ToS 灰色但可行
   - 600 句语音已生成，切换成本高

2. **Sprint 6+（V1+ 商业化）**：切换 Azure 付费版
   - 预算追加 60 元（600 句重生成）
   - voice_generator.py 加 `--provider azure` 参数
   - 一次性迁移，后续 DLC 全走 Azure

### 切换成本

| 项 | 成本 |
|---|---|
| Azure 订阅费 | 60 元（一次性） |
| voice_generator.py 改造 | 2h（王码） |
| 600 句重生成 | 4h（自动脚本） |
| 素材替换验证 | 2h（陈验） |
| **合计** | **60 元 + 8h** |

### 迁移计划（V5+ 执行）

- D1：Azure 订阅申请
- D2：voice_generator.py 改造
- D3：600 句重生成
- D4：素材替换 + 冒烟
- D5：交付

## 关键指标

| 指标 | 当前（Edge） | 目标（Azure） |
|---|---|---|
| 单价 | 0 元 | 4 元/万字符 |
| 商用权限 | 灰色 | 明确 |
| 音色完整度 | 有限 | 完整 |
| SLA | 无 | 99.9% |

## 结论

- ✅ V1 首发用 Edge TTS（0 元，可行）
- ✅ V5+ 商业化切 Azure 付费版（60 元，2024-11 前后执行）
- ✅ R-024 应对方案落地，Sprint 5 无需追加预算
