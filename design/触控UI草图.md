# 触控 UI 草图（Android）

> 维护人：赵画（美术/资源师）
> 版本：v0.1（Sprint 0 D3）
> 关联：R-015（双平台维护）、R-018（触屏误触）
> 目标分辨率：1080×1920（竖屏）/ 1920×1080（横屏，横版游戏用）

---

## 一、触控 UI 设计原则

| 原则 | 说明 |
|---|---|
| 按钮最小 96×96 px | Android 官方触控阈值 |
| 按钮间距 ≥16 px | 防误触 |
| 主操作按钮置底 | 拇指热区优先 |
| 关键操作二次确认 | 跳过/退出/删除 |
| 拖拽区域清晰 | 用箭头/高亮引导 |
| 不共用鼠标 UI 组件 | 独立目录 `assets/ui/touch/` |

## 九、与鼠标 UI 的差异对比

| 项 | 鼠标 UI | 触控 UI |
|---|---|---|
| 按钮尺寸 | 64×64 | 96×96 |
| 按钮间距 | 8 | 16 |
| 字号 | 16-20 | 24-32 |
| 图标 | 24×24 | 48×48 |
| 交互 | 悬停高亮 | 按下高亮 |
| 跳过按钮 | 无长按 | 长按 500ms + 二次确认 |
| 立绘区域 | 720×1280 | 400×600（横屏） |
| 对话框 | 1200×280 | 820×220 |
