# 项目计划

> 项目：《堕落者们的阿尔卡迪亚》
> 维护人：张策（项目经理）
> 版本：v0.1（Sprint 0 立项）
> 立项日：2024-09-09

## 一、项目定位（团队对齐）

| 项 | 定论 | 拍板人 |
|---|---|---|
| 游戏类型 | 2D 回合制 RPG + 剧情驱动 + 养成 | 李游 |
| 视角 | 俯视 45° | 李游 |
| 画风 | 日系厚涂立绘 + 半像素地图 + 暗黑哥特 UI | 赵画 |
| 引擎 | **Godot 4.3**（稳，H 社区生态好，Steam 支持） | 王码 |
| 平台 | **Steam 首发 + Web 引流 + Android APK（同步 MVP，官网侧载）** | 张策+用户拍板 |
| 分级 | **纯 18+，无分级** | 用户拍板 |
| 主角 | 堕落勇者「凯尔」，男 | 李游 |
| 女主数 | 首发 5 位：Artesia / Marina / Mei / Rushena / Meido | 李游 |
| 特色要素 | 战败可捕获 ✅ 触手 ✅ 怪物化 ✅ NTR ✅ 调教系统 ✅ | 用户拍板 |
| 素材策略 | MVP 复用 RMMZ 提取素材，正式版前 3 个月启动替换 | 张策+赵画 |

## 二、Sprint 计划（MVP 4 周）

### Sprint 0（D1-D7）：MVP 骨架

| 天 | 目标 | 主责 |
|---|---|---|
| D1 | 立项 + 测试骨架 + 素材盘点 | 张策/陈验/赵画 ✅ 已完成 |
| D2 | Godot 空工程 + 目录结构 + **Android 导出脚本骨架 + CI 双平台分支** | 王码 |
| D3 | 战斗原型（1v1 回合制） | 王码 |
| D4 | 事件系统框架 + 剧情脚本解析器 | 王码 |
| D5 | 存档系统（3 槽+自动+版本迁移） | 王码 |
| D6 | 立绘切换 + H 事件触发器 + UI 草图定稿 | 王码+赵画 |
| D7 | 素材导入层 + Sprint 0 冒烟测试 + 交付 | 全员 |

### Sprint 1（D8-D21）：主线第一章

- 完整战斗系统（技能/克制/Buff/战败捕获）
- 完整 H 系统（调教基础 3 动作 + 5 道具）
- 第一章脚本 + Artesia 攻略线
- UI 全套定稿
- 存档完整化

### Sprint 2（D22-D35）：多女主拓展

- Marina / Mei / Rushena / Meido 攻略线
- 调教进阶（触手/羞辱/道具组合）
- 结局分支（17 个结局分布）
- 女仆日常系统

### Sprint 3+（Sprint 36+）：Steam 上架准备

- 素材替换（授权谈判/原创外包）
- i18n 框架（如需多语言）
- 性能优化
- Steam 上架资质申请

### Sprint 4（D36-D49）：Steam + APK 双平台交付

- Steam 版：完整版（含 3D 演出全开）
- Android APK：降级版（3D 演出关闭，2D CG 替代；触控 UI；面数砍到 5000）
- Android 分发：官网直下 APK（不做 Play 商店，规避分级）
- Android 云存档（手机重装/换机场景）

## 五、变更控制

1. 需求变更必须书面（本文件记录）
2. 全员通知（群消息/看板）
3. 变更影响评估：工时 + 风险 + 优先级
4. 张策审批，未审批变更无效
