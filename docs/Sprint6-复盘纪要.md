## 三、待改进（5 项）

### 1. 剧本 JSON schema 校验缺失
B-05 H-MA-003 event_id 拼写错误 ma003 vs ma-003，V1 内 <6h 修复，但根因是剧本 JSON 无自动化 schema 校验。**Sprint 7 S7-06 补自动化校验**。

### 2. SaveManager null-safe 加固
B-01 Android 存档读档偶发崩溃（<0.3%），deserialize 空指针兜底已加，但缺 null-safe 断言。**Sprint 7 S7-07 补**。

### 3. AudioManager 多平台回归矩阵缺失
B-04 结局 15 BGM Mac 静音，D6 全量回归只测 Steam PC + Android，未覆盖 macOS。**Sprint 7 S7-08 补 macOS 到测试矩阵**。

### 4. Steam 商店页素材兼容性 checklist 缺失
B-03 Steam 商店页视频 Win7 黑屏，商店页素材（MP4/图片）未列入 V1 首发兼容性 checklist。**Sprint 7 S7-09 补**。

### 5. 张策每日站会节点误判
D5、D6 张策两次误判时间线（先 grep 确认前已落 D3 内容），浪费 2 次工具调用。**Sprint 7 D1 起每日站会前强制 grep_code 确认当前节点**。
