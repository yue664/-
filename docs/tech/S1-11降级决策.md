> 负责人：张策

> 关联风险：R-026

## 决策背景

- Sprint 0 D5 提出 S0-05c GitHub 仓库任务
- Sprint 1 D1 用户无响应，升级为 🔴 阻塞
- Sprint 1 D2 继续无响应
- D3 上午最终决策：走本地 git 分支方案，CI 暂缓接入

## 决策

**采用本地 git 分支方案**：

1. 张策本地初始化 `.backup/.git` 作为主分支 `main`
2. 每个 Sprint 打 tag（v0.1.0 / v0.2.0 / v0.3.0 ...）
3. 王码主分支开发，张策每日 push 快照到 `.backup/`
4. CI 暂缓接入，改用 `tools/smoke.sh` 本地跑（王码 D3 交付）
5. Sprint 3 前如果用户提供 GitHub 账号，切到远程

## 影响

- ✅ R-026 关闭（本地方案替代）
- 🟡 CI 无法自动跑 → 陈验每日手工冒烟替代（成本 +20 分钟/日）
- 🟡 GitHub Actions 三平台构建暂缓 → Sprint 3 补做
- ✅ 不阻塞 Sprint 1 交付
