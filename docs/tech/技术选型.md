## 一、引擎选型

| 项 | 定论 | 理由 |
|---|---|---|
| 引擎 | **Godot 4.3** | 稳，H 社区生态好，Steam + Android 双平台导出完整 |
| 语言 | GDScript（主）+ C#（可选，性能热点） | 团队熟悉，迭代快 |
| 渲染 | GL Compatibility（跨平台保底）+ Forward+（PC 高配） | 兼容 Intel 核显与老显卡 |
| 目标版本 | Godot 4.3（Sprint 3 评估迁移 4.4） | 4.4 目前 Shader 系统有变，暂不追 |

**为什么不用 Unity**：
- Unity 2022+ 有运行时收费风险（$3k/10 万美元以上营收），18+ 独立游戏回本不确定
- Unity H 社区生态远不如 Godot
- 3D 演出规模不大，Godot 4.3 够用

**为什么不用 Godot 4.4**：
- 4.4 的 Shader 系统重构，Cel-Shading 社区模板未同步
- Steam 上架时间更紧，稳比新重要
- Sprint 3 复盘时再评估

## 三、平台分层设计（Android 骨架核心）

### 3.1 平台检测：`PlatformManager.gd`

- `current_platform`：枚举 `STEAM_PC` / `ANDROID` / `WEB`
- `is_high_perf_3d`：**手机端默认 false**（关闭 3D 演出）
- `use_touch_ui`：**手机端默认 true**（启用触控 UI）
- `save_dir_base`：按平台自动切换（PC=savegame_dir / Android=user_data_dir）

### 3.2 降级规则

| 特性 | Steam PC | Android |
|---|---|---|
| 3D 立绘演出 | ✅ 全开 | ❌ 关闭 |
| H 事件演出 | 3D 模型 + Blend Shape | 2D CG 替代 |
| UI 交互 | 键盘鼠标 | 触控（按钮 +40% 尺寸） |
| 3D 模型面数 | 1-2 万面 | 5000 面 LOD |
| Cel-Shading | 有描边 | 简化/关闭描边 |
| 存档 | 桌面本地 | 应用沙箱 + 云存档预留 |

### 3.3 双平台分支约定

- `main` 分支：双平台同步 CI（Windows + Android + Web）
- `feature/*` 分支：正常开发
- 平台专用代码统一放在 `scripts/platform/` 下
- 用 `PlatformManager.is_android()` / `PlatformManager.can_use_3d_cinematic()` 判断，**禁止硬编码 `#ifdef` 宏**（GDScript 4.3 宏系统有限，运行时判断更灵活）

## 七、代码规范（GDScript 4.3）

- **缩进**：Tab（不用空格，Godot 编辑器默认）
- **命名**：
  - 变量/函数：`snake_case`
  - 类/信号：`PascalCase`（类）/ `snake_case`（信号）
  - 常量：`UPPER_SNAKE_CASE`
- **类型标注**：强制（`var x: int` / `func f(a: int) -> bool`）
- **信号**：命名 `verb_过去式`（`hp_changed` 而非 `changeHp`）
- **文件头**：文件用途 + 维护人 + 版本
- **导出变量**：用 `@export`，加注释说明取值范围
- **避免全局状态**：核心状态走 GameManager/PlatformManager autoload

## 八、构建与发布

### 8.1 构建命令（本地）

```bash
# 开发调试
godot --path game --editor

# Windows 导出
godot --headless --path game --export-release "Windows Desktop" build/windows/ArkaFall.exe

# Android 导出
godot --headless --path game --export-release "Android" build/android/ArkaFall.apk

# Web 导出
godot --headless --path game --export-release "Web" build/web/index.html
```

### 8.2 Android 导出前置

- Android SDK 34（`minSdk 24` = Android 7.0+）
- JDK 17
- Keystore（签名用）：`debug.keystore` 走 CI secrets，`release.keystore` 走本地
- 打包格式：APK（单 arm64-v8a，减小体积）

### 8.3 CI 产物

- `arka-fall-windows-v0.2.0` — .exe
- `arka-fall-android-v0.2.0` — .apk
- `arka-fall-web-v0.2.0` — html+js+pck
- 产物保留 30 天，最新 tag 保留永久
