# Sprint 10 用例自动化拆分方案（S10-05）

- **任务**：S10-05 用例自动化脚本化（400 条并行 45min → 15min，预算 1,000 元）

- **状态**：🟡 方案落盘（D1 2024-11-13）→ D2 方案定稿 → D4 框架雏形 → D5 接入 CI（可回退）

## 一、目标与现状

| 项 | 现状 | 目标 |
|---|---|---|
| 用例总数 | 400 条（冒烟 20 + 功能回归 ~330 + 跨版本/云存档专项 50） | 400 条全量 |
| 单线程执行 | ~2.5h | — |
| 多线程执行 | ~45min | **≤15min** |
| 结果判定 | 人工看报告 | 自动聚合 + 失败即报 |

## 二、拆分策略（四组并行 + 双端分片）

按优先级切 4 个 worker 组，组内按平台分片，互不依赖可并行：

| 组 | 用例范围 | 占比 | 典型用例 | 执行端 |
|---|---|---|---|---|
| P0 组 | 冒烟 20 + 战斗/H 核心 | ~20% | TC-SMOKE-*、TC-BATTLE-*、TC-H-* | PC 主线程 + Android 模拟器分片 |
| P1 组 | 存档/UI/音频 | ~25% | TC-SAVE-*、TC-UI-*、TC-AUDIO-* | PC 2 线程分片 |
| P2 组 | 3D/边界/性能 | ~30% | TC-3D-*、TC-BOUND-*、TC-PERF-* | PC 3 线程分片 |
| P3 组 | 兼容/跨版本/云存档 | ~25% | TC-COMPAT-*、TC-SAVE 跨版本 23 条、TC-CLOUD-001~005 | Android + 多配置分片 |

**并行度估算**：4 组 × 组内 2-3 分片 ≈ 10-12 并发，单组最长 ~12min，目标 15min 可达。

## 三、技术方案

1. **Runner 框架**：Godot 4.3 测试 runner（复用 GodotTest 接入），命令行参数 `--group=P0 --shard=1/3` 指定分片。
2. **分片调度**：CI 侧脚本（Python，复用已有工具链）读取用例清单 → 按组/平台切分 → 分发 worker → 收集结果 JSON。
3. **结果聚合**：每分片输出 `result_{group}_{shard}.json`，汇总脚本合并 → 失败用例自动关联 Bug 清单编号。
4. **环境隔离**：PC 用 CI runner 多进程；Android 用模拟器实例分片（串行跑，避免资源竞争）。
5. **失败重跑**：单条失败自动重试 1 次（区分 flaky 与真失败），重试仍失败才标红。
