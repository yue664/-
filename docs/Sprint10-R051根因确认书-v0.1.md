## 二、根因链（为什么走到这一步）

1. **Sprint 0 遗留**（CHANGELOG S0-05c）：GitHub 仓库地址**始终等用户提供**，从未落地 → 线上仓库状态长期无人能验证。
2. 原组以"CI checkout 天然有源"（三列合表 v0.1 / KN-017 澄清）推进，**但"线上有源"从未被任何人实际验证过**。
3. Sprint 7/8/9 CG 验收记录齐全（双签、付款、入廊），但那是**验收签字**，不是**资产入库**——真体文件从没进过任何 git 仓库/手机目录/可验证介质。
4. D4 已自认"实物不在工作区"，D5"线上可拉取"钉死为目标，但**没等到执行**原组即裁撤。

**定性：流程坑（验收 ≠ 入库），不是供应商坑。** 若供应商未交付，不会有双签与入廊记录；真体更可能在原组 PC / 供应商网盘 / 线上仓库（未验证）。
