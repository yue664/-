## 热修复流程（v1.0.1 补丁包模板）

### 触发条件

| 严重度 | 触发条件 | 响应时间 | 修复时间 |
|---|---|---|---|
| P0 | 阻断性 Bug（无法启动/存档丢失/付费墙） | <30 分钟 | <2 小时 |
| P1 | 严重 Bug（H 事件崩溃/数值错误/性能严重下降） | <2 小时 | <4 小时 |
| P2 | 一般 Bug（UI 细节/文案/图标） | <8 小时 | <24 小时 |
| P3 | 优化建议 | 下一 Sprint | Sprint 7+ |

### 修复流程

```
1. 值班员发现 P0/P1 Bug → 立即上报张策（30 分钟内）
2. 张策确认热修复必要性 → 通知王码（15 分钟内）
3. 王码定位问题 → 修复 + 单测（<1 小时）
4. 陈验快速回归（<30 分钟）
5. 王码打补丁包（v1.0.1）→ 上传 Steam/Android R2（<30 分钟）
6. 张策发布官方公告（Steam 公告 + 官网公告 + 4 平台微博）
7. 监控面板跟踪热修复后指标
```
