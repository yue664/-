## 目录结构

```
开发项目/
├── README.md              ← 本文件
├── docs/
│   └── 已知问题列表.md    ← 团队共用的风险/TODO 台账

│   ├── 测试用例.md         ← 用例库
│   ├── Bug清单.md          ← Bug 台账

```

## Sprint 计划

- **Sprint 0**（D1-D7）：MVP 骨架 + 冒烟测试
- **Sprint 1**（D8-D21）：主线第一章 + 战斗完整 + H 事件完整
- **Sprint 2**（D22-D35）：DLC 分支 + 5 位女主全攻略
- **Sprint 3+**：Steam 上架准备（素材替换）

## 关键指标

- 测试覆盖率 ≥90%（核心功能）
- P0/P1 清零率 = 100%（发布前）
- 回归通过率 ≥98%
- 兼容性覆盖率 ≥80%
- 性能退化 ≤10%
